Sistem Kontrol Kipas Berbasis Fuzzy Tsukamoto

Pengantar

Dalam kehidupan sehari-hari, kita sering menggunakan istilah seperti "dingin", "hangat", atau "panas" yang bersifat tidak pasti. Logika fuzzy digunakan untuk menangani ketidakpastian tersebut dengan menggunakan derajat keanggotaan antara 0 sampai 1.

Pada aplikasi ini, sistem akan menentukan kecepatan kipas berdasarkan dua input: suhu dan kelembaban, menggunakan metode Tsukamoto.

Aturan Fuzzy

  • IF suhu dingin AND kelembaban kering THEN kipas lambat
  • IF suhu dingin AND kelembaban lembab THEN kipas sedang
  • IF suhu panas AND kelembaban kering THEN kipas sedang
  • IF suhu panas AND kelembaban lembab THEN kipas cepat
